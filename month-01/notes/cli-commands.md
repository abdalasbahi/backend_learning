إليك قائمة شاملة ومجمعة بجميع الأوامر التي تعرضنا لها وتعرفنا عليها حتى الآن في **السطر البرمجي (Terminal / Git Bash / CMD)** و**نظام Git**:

---

### 1️⃣ أوامر الاستكشاف والتنقل (Navigation & Inspection)

* **`pwd`**: عرض مسار المجلد الحالي الذي تقف فيه (Print Working Directory).
* **`ls`**: عرض قائمة الملفات والمجلدات.
* **`ls -la`**: عرض تفصيلي لجميع الملفات والمجلدات بما فيها المخفية.


* **`cd <path>`**: التنقل بين المجلدات (Change Directory).
* **`cd .`**: المجلد الحالي.
* **`cd ..`**: العودة للمجلد الأب (المستوى الأعلى).
* **`cd ~`**: العودة لمجلد المستخدم الرئيسي.
* **`cd -`**: العودة لآخر مجلد كنت فيه.



---

### 2️⃣ أوامر إدارة الملفات والمجلدات (File & Directory Management)

* **`mkdir <dir_name>`**: إنشاء مجلد جديد.
* **`mkdir -p path/to/dir`**: إنشاء سلسلة مجلدات متداخلة دفعة واحدة وتفادي الأخطاء إذا كانت موجودة.
* **`mkdir -p folder/{sub1,sub2}`**: استخدام الأقواس `{}` لإنشاء أكثر من مجلد فرعي داخل نفس المسار دفعة واحدة.


* **`touch <file_name>`**: إنشاء ملف فارغ جديد (أو تحديث تاريخ التعديل).
* **`type nul > <file_name>`**: بديل إنشاء ملف فارغ في Windows CMD.
* **`cp <source> <dest>`**: نسخ ملف.
* **`cp -r <dir1> <dir2>`**: نسخ مجلد بكل محتوياته.


* **`mv <source> <dest>`**: نقل ملف/مجلد أو إعادة تسميته.
* **`rm <file_name>`**: حذف ملف.
* **`rm -rf <dir_name>`**: حذف مجلد بكل محتوياته بشكل نهائي وبدون تأكيد.



---

### 3️⃣ أوامر قراءة واستكشاف محتوى الملفات (File Inspection)

* **`cat <file_name>`**: طباعة كامل محتوى الملف داخل الطرفية دفعة واحدة.
* **`head -n <N> <file_name>`**: عرض أول `N` أسطر من الملف (مثال: `head -n 5 cli-commands.md`).
* **`tail -n <N> <file_name>`**: عرض آخر `N` أسطر من الملف.
* **`tail -f <log_file>`**: المراقبة الحية والحيّة للسطور الجديدة التي تُضاف إلى الملف باستمرار (يُخرج منه بـ `Ctrl + C`).

---

### 4️⃣ أوامر البحث والمعالجة وإعادة التوجيه (Pipes, Redirection & Search)

* **`echo "text"`**: طباعة نص في الطرفية.
* **`>`**: رمز إعادة التوجيه والتغطية (Overwrite)؛ يكتب النص في الملف ويمسح محتواه القديم.
* **`>>`**: رمز إعادة التوجيه والإلحاق (Append)؛ يضيف النص في نهاية الملف مع الحفاظ على المحتوى القديم.
* **`|` (Pipe)**: تمرير مخرجات أمر ليكون مدخلاً لأمر آخر (مثال: `ls -la | grep "notes"`).
* **`grep "search_term" <file_name>`**: البحث عن كلمة أو نص محدد داخل الملف بطباعة الأسطر التي تحتويه.
* **`find <path> -name "filename"`**: البحث عن موقع ملف أو مجلد داخل شجرة النظام.

---

### 5️⃣ أوامر الصلاحيات والتحكم (Permissions)

* **`chmod +x <script.sh>`**: إعطاء صلاحية التنفيذ لملف.
* **`chmod 755 <file>` / `chmod 600 <file>**`: تغيير صلاحيات الوصول للقراءة والكتابة والتنفيذ.

---

### 6️⃣ أوامر نظام التحكم بالنسخ (Git Basics - الأسبوع الثاني)

* **`git init`**: تحويل المجلد الحالي إلى مستودع Git محلي وإظهار مجلد `.git`.
* **`git status`**: فحص حالة الملفات ومعرفة الملفات المعدلة، المخزنة، والمستبعدة.
* **`git add <file_name>`**: نقل ملف محدد إلى منطقة التجهيز (Staging Area).
* **`git add .`**: نقل جميع الملفات والتعديلات الحالية إلى الـ Staging Area.


* **`git commit -m "commit message"`**: تسجيل نقطة حفظ دائم في المستودع المحلي مع رسالة توضيحية.
* **`git log`**: استعراض سجل التاريخ والتغييرات كاملة.
* **`git log --oneline`**: عرض سجل التاريخ بشكل مختصر ومكثف في خطوط فردية.git

### 5️⃣ أوامر البيئة والمعلومات (System & Environment)

* **`whoami`**: عرض اسم المستخدم الحالي.
* **`history`**: عرض قائمة بجميع الأوامر السابقة التي قمت بكتابتها.
* **`clear`** (أو **`Ctrl + L`**): تنظيف شاشة الطرفية ومسح السطور القديمة.

### 6️⃣ أوامر نظام التحكم بالنسخ (Git Basics)

* **`git init`**: تحويل المجلد الحالي إلى مستودع Git محلي وإنشاء مجلد `.git` المخفي.


* **`git config --global user.name "Name"`**: إعداد اسم الكاتب لـ Git.


* **`git config --global user.email "Email"`**: إعداد البريد الإلكتروني للكاتب لـ Git.


* **`git status`**: فحص حالة الملفات والتعديلات بين Working Directory و Staging Area.


* **`git add <file>`**: نقل ملف محدد إلى منطقة التجهيز (Staging Area).


* **`git add .`**: نقل جميع التعديلات والملفات للمشروع إلى منطقة التجهيز دفعة واحدة.




* **`git commit -m "message"`**: حفظ التغيرات المجهزة في الـ Staging بصفة دائمية برفق رسالة توضيحية.


* **`git log`**: عرض السجل التاريخي للـ Commits.


* **`git log --oneline`**: عرض السجل بشكل مختصر ومكثف في خطوط فردية.




* **`rm -rf .git`**: إزالة تتبع Git من المجلد وتصحيح مشكلة المستودعات المتداخلة.
